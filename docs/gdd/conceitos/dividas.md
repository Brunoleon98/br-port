# 🏦 Sistema de Dívidas

> O banco tem um rosto

*A dívida não é um contador de game over. É um personagem.*

| | |
|---|---|
| **Total herdado** | R$ 3.300.000 em 3 parcelas ao longo de 12 semanas |
| **Parcela 1 (sem. 4)** | R$ 550.000 — pequena, qualquer ritmo cobre. Tutorial de sobrevivência. |
| **Parcela 2 (sem. 8)** | R$ 1.100.000 — exige contrato de frete ativo. Ponto dramático central. |
| **Parcela 3 (sem. 12)** | R$ 1.650.000 — Sr. Abutre aparece antes como comprador. Ato simbólico. |
| **Atraso 1 semana** | Juros de 5%/dia. Sr. Ribeiro visita — cena tensa, sem penalidade mecânica. |
| **Atraso 2 semanas** | Vaga do píer penhorada. Relação com pescadores cai. Arlindo comenta. |
| **Atraso 3 semanas** | Banco notifica execução. Abutre oferece resgate — aceitar = final ruim. |
| **Válvulas de escape** | Renegociação única / Vaquinha da comunidade / Contrato de emergência / Venda de ativo |
